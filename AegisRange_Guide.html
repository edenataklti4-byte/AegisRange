What is AegisRange in 1 Plain Sentence?

AegisRange is a safe, isolated virtual practice arena with 3 virtual computers where you launch simulated cyber attacks, capture the digital evidence, and watch a dashboard reconstruct exactly what happened and when.

1

The Virtual Lab (The 3 Machines)

Three virtual computers running inside your host PC, connected through an isolated private subnet (10.10.10.0/24):

Attacker 10.10.10.10

🔴 Kali Linux

The simulated adversary. Launches Hydra password guessing and hosts the malware payload.

Target 1 10.10.10.20

🟢 Ubuntu Server

Company server target. Runs SSH and generates authentication logs (/var/log/auth.log).

Target 2 10.10.10.30

🔵 Windows 10

Workstation PC target. Telemetry generated with Sysmon (Process, File, Registry, Network).

The 2 Attack Scenarios

Linux Target • MITRE T1110.001

Scenario 1: SSH Brute-Force

  • 1. Kali scans Linux target port 22 with Nmap.
  • 2. Hydra tests ~25 passwords rapidly, generating failed auth logs.
  • 3. Succeeds with labpass123.
  • 4. Runs post-login commands: whoami, cat /etc/passwd.
Target Evidence: /var/log/auth.log
Windows Target • MITRE T1059.001 / T1105

Scenario 2: Malware Dropper

  • 1. PowerShell downloads payload from Kali HTTP server.
  • 2. Saves file into C:\Users\Public\payload.exe.
  • 3. Executes payload and adds a Registry Run key (persistence).
  • 4. Initiates TCP callback to Kali on port 4444.
Target Evidence: Sysmon EID 1, 3, 11, 13

Step-by-Step Delivery Roadmap

Week 1

Lab & Arch

Member 1 spins up the 3 VMs using Vagrant and validates network ping connectivity.

Week 2

Fire Attacks

Member 2 executes the 2 attack scripts, confirms raw evidence appears, and saves sample logs.

Week 3

Detect & Correlate

Member 3 collectors POST /api/logs to Member 4's main.py; 3+ logs from one source IP in 5 min raise an incident.

Week 4

Streamlit Demo

Member 5 launches Streamlit on app.db. You run an attack live $\rightarrow$ incident appears on the dashboard!
